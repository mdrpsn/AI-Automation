# AI-Automation

Working portfolio of AI/automation builds. Each one is a real, importable workflow built to solve a specific business problem — used as proof-of-work for landing freelance automation clients, not as a design showcase.

## Method: Learn → Build → Sell

- **Learn**: pick up exactly enough of a tool or concept to ship the current project. No tutorials for their own sake.
- **Build**: ship something a real business could plug in and use, scoped to a real problem, not a toy demo.
- **Sell**: the finished build becomes proof-of-work — a short demo + case study — used directly in freelance outreach (Upwork, cold outreach, referrals).

## Focus niche

Home-service businesses: HVAC, plumbing, electrical, cleaning, salons, contractors. Reasoning: they lose real money to slow lead response and no-shows, they have no in-house dev, the sales cycle is short, and most automation freelancers chase flashier niches (SaaS, e-commerce) — so there's less competition here.
